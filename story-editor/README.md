# 剧情编辑器 (Story Editor)

一个功能完备的 Galgame 视觉小说剧情编辑器，支持节点式剧情创作、角色管理、背景系统、变量分支、实时预览等功能。

---

## 快速开始

### 运行剧情编辑器需要 main.py 吗？

**视功能而定：**

| 功能 | 需要 main.py | 说明 |
|------|-------------|------|
| 打开编辑器页面 | ❌ 不需要 | 纯静态 HTML，直接双击 `index.html` 也能用 |
| 节点编辑 / 场景管理 | ❌ 不需要 | 纯前端操作，数据存在浏览器 LocalStorage |
| 导出 JSON 文件 | ❌ 不需要 | 纯前端下载 |
| 导入 JSON 文件 | ❌ 不需要 | 纯前端上传 |
| **从资产导入角色** | ✅ **需要** | 需要后端 API 读取本地文件 |
| **保存 / 加载剧情到服务器** | ✅ **需要** | 需要后端读写 JSON 文件 |
| **AI 角色生成** | ✅ **需要** | 需要后端调用 Seedream API |
| **批量抠图** | ✅ **需要** | 需要后端调用 mediakit |

**推荐使用方式**：通过 `python main.py` 启动服务，享受完整功能。

### 启动方式

```bash
# 1. 安装依赖（首次使用）
pip install fastapi uvicorn pydantic

# 2. 启动服务
cd /workspace
python main.py

# 3. 在浏览器中打开
# http://localhost:8000/story-editor/
```

## 功能介绍

### 🎬 场景管理

- 创建、删除、重命名场景
- 拖拽调整场景顺序
- 设置起始场景
- 场景间跳转（jump 节点 / choice 节点）

### 📝 节点编辑

支持 13 种节点类型：

| 类型 | 图标 | 说明 |
|------|------|------|
| 对话 | 💬 | 角色说话，显示名字和文本 |
| 旁白 | 📖 | 叙述文本，不显示角色名 |
| 选择支 | 🔀 | 提供多个选项，分支剧情 |
| 跳转 | ⏭️ | 跳转到指定场景/节点 |
| 条件 | ❓ | 根据变量决定走哪条分支 |
| 设置变量 | 🔧 | 设置/修改变量值 |
| 切换背景 | 🖼️ | 更换背景图，支持过渡动画 |
| 显示角色 | 👤 | 显示角色立绘，支持位置和过渡 |
| 隐藏角色 | 🙈 | 隐藏已显示的角色 |
| 特效 | ✨ | 屏幕特效（震动、闪光、淡入等） |
| 音效 | 🔊 | 播放音效/BGM |
| 等待 | ⏱️ | 等待指定时间 |
| 结束 | 🔚 | 场景/剧情结束 |

**操作方式**：
- 点击"+ 添加节点"按钮添加节点
- 拖拽节点调整位置
- 点击节点查看/编辑属性
- 在属性面板设置"下一节点"建立连线

### 👤 角色管理

- 从资产库导入已有角色
- AI 创建新角色（Seedream 生成 + 自动抠图）
- 手动添加/编辑角色
- 每个角色支持多个表情/姿态立绘

#### 从资产导入角色

1. 切换到"👤 角色"标签页
2. 点击"📥 从资产导入"
3. 在弹出的列表中选择角色，点击"导入"

> 💡 如果提示"资产中没有找到角色"，请检查：
> - 后端服务是否启动（`python main.py`）
> - `story-editor/assets/characters/` 目录是否存在角色文件夹
> - 点击"🔄 刷新"按钮重试

#### AI 创建新角色

1. 切换到"👤 角色"标签页
2. 点击"✨ AI 创建"按钮
3. 填写角色名称、外貌描述
4. 选择需要的表情和姿态
5. 点击"生成"，等待 AI 创作
6. 确认效果后保存到资产库

### 🖼️ 背景管理

- 纯色背景 / 图片背景
- 多种过渡动画（淡入淡出、滑动、溶解等）
- 支持自定义背景图

### ⚙️ 变量系统

- 全局变量存储剧情状态
- 支持数字、字符串、布尔值
- 条件节点根据变量值分支
- 可与 RPG 游戏主程序同步变量

### ▶️ 实时预览

- 底部预览面板即时播放
- 支持播放/暂停/快进/重置
- 完整还原视觉小说效果
- 测试分支选择是否正确

### 💾 导入 / 导出

- **保存到服务器**：💾 按钮，数据存到 `story-editor/stories/`
- **从服务器加载**：📂 按钮，打开已保存的剧情
- **导出 JSON**：⬇️ 按钮，下载到本地文件
- **导入 JSON**：⬆️ 按钮，从本地上传

## AI 角色创建

### API Key 配置

在使用 AI 角色创建前，需要配置 API Key（环境变量）：

```bash
# Seedream 生图 API（必填）
export ARK_API_KEY="your-api-key-here"
# 或者
export MODEL_IMAGE_API_KEY="your-api-key-here"

# 抠图 API（可选，不配置则跳过抠图）
export MEDIAKIT_API_KEY="your-mediakit-key"
```

### 使用步骤

1. 点击角色面板的"✨ AI 创建"按钮
2. 填写角色基础信息：
   - **角色名称**：角色的中文名称
   - **角色 ID**：英文标识符（自动生成，可修改）
   - **代表色**：角色主题色
3. 描述外貌特征（中文）：
   - 发型、发色、五官
   - 服装、配饰
   - 性格气质
   - 其他细节
4. 选择风格预设：
   - 像素画（128×128，推荐）
   - 二次元
   - 写实
5. 选择需要的表情/姿态（默认 8 个）
6. 点击"开始生成"
7. 等待生成完成，可以单张重新生成
8. 点击"保存到资产库"

### 预设表情说明

| 类别 | 名称 | 说明 |
|------|------|------|
| 基础表情 | neutral | 平静/中性 |
| | happy | 开心/微笑 |
| | sad | 悲伤/难过 |
| | angry | 愤怒/生气 |
| | surprised | 惊讶/吃惊 |
| | thinking | 思考/沉思 |
| | laughing | 大笑/嘲笑 |
| | defeated | 挫败/失落 |
| | victory | 胜利/得意 |
| | scheming | 狡黠/计谋 |
| | shy | 害羞/腼腆 |
| | crying | 哭泣/流泪 |
| 姿态 | idle | 站立待机 |
| | thinking_pose | 思考姿势 |
| | pointing | 手指前方 |
| | cheering | 欢呼 |
| | crossed_arms | 抱臂 |
| | walking1/2 | 行走动画帧 |
| | portrait | 头像特写 |

### 抠图功能

生成的图片默认会自动去除背景，保存为透明 PNG。如果抠图效果不理想：
- 可以在确认页对比原图和抠图结果
- 单张图片可以选择保留原图
- 批量抠图工具可以重新处理已有资产

## 常见问题

### Q: 点击"从资产导入"提示"资产中没有找到角色"怎么办？

**排查步骤**：
1. 确认后端服务正在运行（`python main.py`）
2. 确认 `story-editor/assets/characters/` 目录存在
3. 确认该目录下有角色子文件夹（每个文件夹对应一个角色）
4. 点击对话框中的"🔄 刷新"按钮重试
5. 如果还是没有，查看对话框中的调试信息（目录路径、扫描数量等）

### Q: 预览时角色图片不显示怎么办？

- 确认后端服务正在运行（图片通过 `/assets/` 路径提供）
- 确认图片文件存在于 `story-editor/assets/characters/` 下
- 打开浏览器开发者工具，查看 Network 面板是否有 404 错误

### Q: 如何备份我的剧情？

- 点击"⬇️ 导出"按钮，下载 JSON 文件到本地
- 定期保存到服务器（💾 按钮），数据存在 `story-editor/stories/` 目录
- 建议同时导出 JSON 备份

### Q: 可以直接打开 index.html 使用吗？

可以，但以下功能不可用：
- 从资产导入角色
- 保存/加载剧情到服务器
- AI 角色生成
- 批量抠图

核心的节点编辑、场景管理、实时预览、导入导出 JSON 等功能都可以正常使用。

### Q: AI 生成角色需要多长时间？

取决于生成的图片数量：
- 默认 8 张：约 1-2 分钟
- 全部 20 张：约 3-5 分钟
- 单张重新生成：约 10-20 秒

生成过程中可以随时查看进度，不满意的可以单独重新生成。

## 技术栈

- **前端**：原生 JavaScript + HTML5 + CSS3
- **后端**：FastAPI (Python)
- **节点画布**：SVG 连线 + DOM 节点拖拽
- **预览引擎**：原生 JS 实现的视觉小说播放器
- **AI 生图**：火山引擎 Seedream
- **抠图**：火山引擎 MediaKit
