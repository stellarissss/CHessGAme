# 09 识破概率数学模型与技能系统

## 摘要

本分册给出本项目「被天道识破」概率的数学模型及其在代码与设计书中的定义，并完整列出技能树四个分支的技能修饰符。核心公式为 `Δ = C × O^α`：每次业力溢出后，按溢出量 `O`、惩罚系数 `C`、非线性指数 `α` 计算识破概率增量，累加为道级全局识破概率；再掷骰判定是否识破。被识破的后果不是重置进度，而是「锁死」业力并强制后续天道 Boss 战。本分册给出公式推导、代入验算、边界饱和分析，以及技能修饰符的逐项出处。

## 1 背景与问题定义

业力超出安全阈值（默认 120）的部分称为溢出量 `O`。系统需要在「每次作弊」与「最终被天道识破」之间建立一条可解释、可调参、非线性放大的概率关系，使得：

- 小溢出几乎安全（鼓励小步透支而非一次性豪赌）；
- 大溢出几乎必死；
- 识破概率在「道」内跨关卡累计，且可由技能调节。

问题定义：给定溢出量 `O`，如何计算本次溢出带来的识破概率增量 `Δ`，并在多次溢出后给出当前累计识破概率，再据以判定是否识破。

## 2 相关做法与本方案的区别

通用反作弊系统多采用线性阈值或固定概率。本方案的区别：

- 采用幂律非线性 `O^α`（`α=1.5`），使识破概率对大溢出敏感、对小溢出迟钝（设计书 §4.7）。
- 识破概率是**道级全局变量**（`realm_detections[realm]`），跨关卡保留、换道清零（`samsara/detection.py` 相关；设计书 §4.4）。
- 被识破不重置进度，而是「锁死」业力、保留全部进度，并强制后续天道 Boss 战（设计书 §4.5.2）。这与常见惩罚式重置不同。

## 3 技术方案

### 3.1 公式定义

设计书 §4.1 与 `shared/karma_assessor_base.py:333-355` 给出：

```
Δ = C × O^α
```

各符号含义与量纲：

| 符号 | 含义 | 量纲 / 取值 | 默认值 |
|:----:|:-----|:-----------|:------:|
| `O` | 业力超出安全阈值的部分（溢出量） | 整数点数，≥0 | — |
| `C` | 惩罚系数 | 无量纲概率系数 | 0.1 |
| `α` | 非线性指数 | 无量纲 | 1.5 |
| `Δ` | 本次溢出带来的识破概率增量 | 百分数（%） | — |

当 `O ≤ 0` 时 `Δ = 0`（无溢出不增加识破概率，`shared/karma_assessor_base.py:344-345`）。

### 3.2 关键参数（设计书 §二 / §3.2 / §4.1）

- `initial_karma = 50`：关卡起始业力（受「净身」技能减免）。
- `karma_max = 120`：安全阈值，超出部分计入 `O`。
- `karma_single_max = 120`：单次作弊增量上限，超出直接拦截、业力不变。
- `C = 0.1`：「藏锋」技能降至 0.07（`detection_coefficient = 0.07`）。
- `α = 1.5`：「缓冲」技能降至 1.3（`detection_alpha = 1.3`）。

### 3.3 公式推导

由定义，`Δ` 是溢出量 `O` 的幂函数。取 `C`、`α` 为默认值时：

```
Δ(O) = 0.1 × O^1.5
```

由于 `O^1.5 = O × √O`，可改写为 `Δ = 0.1 × O × √O`。这意味着增量随 `O` 超线性增长：溢出量翻倍，增量变为约 `2^1.5 ≈ 2.83` 倍。这正是设计意图「小透支可控、大透支几乎必死」的来源（设计书 §4.7）。

累计识破概率为道内所有 `Δ` 之和，封顶 100%（设计书 §4.2 脚注）。

### 3.4 代入验算

取 `C=0.1`、`α=1.5`，逐点代入并与设计书校准表（§4.2）核对：

| `O` | 计算过程 | `Δ`（计算） | 设计书值 | 一致 |
|:---:|:--------|:-----------|:--------:|:----:|
| 10 | 0.1 × 10^1.5 = 0.1 × 31.6228 | 3.16% | 3.16% | 是 |
| 20 | 0.1 × 20^1.5 = 0.1 × 89.4427 | 8.94% | 8.94% | 是 |
| 30 | 0.1 × 30^1.5 = 0.1 × 164.317 | 16.43% | 16.4% | 是（四舍五入） |
| 50 | 0.1 × 50^1.5 = 0.1 × 353.553 | 35.36% | 35.4% | 是（四舍五入） |
| 80 | 0.1 × 80^1.5 = 0.1 × 715.542 | 71.55% | 71.6% | 是（四舍五入） |
| 100 | 0.1 × 100^1.5 = 0.1 × 1000 | 100.00% | 100% | 是 |
| 150 | 0.1 × 150^1.5 = 0.1 × 1837.12 | 183.71% | 100%（封顶） | 是（截断） |

验算结论：默认参数下，`O=100` 精确对应 `Δ=100%`；`O>100` 时因封顶而失去区分度；`O=150` 的计算值 183.71% 需截断为 100%。

### 3.5 触发判定与后果

每次业力溢出后（`shared/karma_assessor_base.py:357-422`）：先算 `Δ`，累加进道级识破概率并封顶 100（`handle_overdraft`，`:392`），随后掷骰 `roll = random.random() × 100`，若 `roll < 当前识破概率` 则识破（`:395-396`）。

被识破后果为「锁死」而非重置（设计书 §4.5.2）：

```
level_karma = 0
realm_detections[current_realm] = 0.0
detection_triggered = True
```

即保留全部进度，业力锁死为 0，继续通关六道后强制天道 Boss 战。

「金蝉脱壳」技能：识破触发时，识破概率回退到触发前的 50%，免死一次（`shared/karma_assessor_base.py:399-408`，`golden_escape = True`）。

退还机制（设计书 §3.6）：E 类闲聊成功 +1 点，被拒则全额退还；修改失败（`rejected` / `error`）全额退还；单次上限拦截（`karma_blocked`）业力不变。

## 6 局限性

- **公式饱和**：`O ≥ 100` 时 `Δ` 已封顶 100%，该区间失去区分度；`O=150` 的计算值 183.71% 必须截断（见第 3.4 节）。这意味着「溢出 100 点」与「溢出 150 点」在判定上不可区分。
- **双源一致性风险**：识破与业力存在两套实现（进程内 `KarmaAssessorBase` 与服务端 `samsara/karma_assessor.py`），双源逻辑由人工同步，是已知工程风险（详见 08 分册 §6）。
- **LLM 评分不可复现**：`Δ` 的上游输入（业障值）由 LLM 裸整数打分给出，受采样不确定性影响，故整条因果链从「指令」到「识破概率」不具备可复现性（详见 08 分册 §6）。
- **参数未经标定**：`C`、`α`、各分类价目区间均为设计取值，缺标定实验支撑其对「作弊严重程度」的判别效度。
- **escap 回合的离散性**：每次溢出触发一次判定回合（下称 escap 回合），识破概率离散累加；在 `Δ` 封顶区间内，额外的溢出不再改变被识破风险，可能造成玩家误判风险已稳定。
