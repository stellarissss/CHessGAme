### 3.2 后端冒烟测试（5.1）

**What**：验证后端导入 + 启动 + 5 个核心 API。

**How**（按序执行）：
1. `cd /workspace/heibaiqi && timeout 5 python -c "import main; print('IMPORT_OK')"` → 无报错
2. 后台启动 `python main.py`（端口 8003，非阻塞）
3. 等待 2-3s 后 `curl -s http://localhost:8003/api/config/all` → JSON 含 6 配置键（board_state/board/pieces_black/pieces_white/rules/ui_config）
4. `curl -s -X POST http://localhost:8003/api/valid_moves -H "Content-Type: application/json" -d '{"side":"black"}'` → `moves` 含 4 个初始合法点（[2,3],[3,2],[4,5],[5,4]）
5. `curl -s -X POST http://localhost:8003/api/move -H "Content-Type: application/json" -d '{"to":[2,3]}'` → `success:true`，`flipped` 含 1 个 id（black_disc_1@(4,3) 被翻为 black）
6. `curl -s -X POST http://localhost:8003/api/undo` → `success:true`，board_state 恢复初始 4 disc
7. 验证完毕后停止后端进程

**Why**：确认 flip 原语、合法落子点计算、翻转逻辑、悔棋恢复均正确。
