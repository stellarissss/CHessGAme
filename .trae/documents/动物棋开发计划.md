## 摘要

在 `/workspace/dongwuqi/` 新建"无限制动物棋"子项目，借鉴 `xiangqi/`（无限制象棋）的完整结构与逻辑，复用通用基础设施（jump/ray 原子体系、where 条件引擎、二级 AI 流水线、JSON Patch、机制引擎、Minimax AI、Web Component 前端），将一切领域知识层（棋盘几何、棋子规则、提示词、JSON 配置、Schema、前端文案与贴图）改为动物棋语义。**核心创新**：重新设计 JSON 原语以表达动物棋的"等级吃子 / 鼠克象 / 河流 / 陷阱 / 兽穴 / 狮虎跳河"机制，并遵循"灵活编码"最高纲领——所有规则皆由 JSON 驱动、AI 可现场修改。

## 一、动物棋规则（基于搜索研究）

### 1.1 棋盘（7 列 × 9 行 = 63 格，棋子在**格内**而非交叉点）

- **坐标系**：`[x, y]`，x: 0-6（左到右），y: 0-8（上到下）。黑方在上(y:0-2)，红方在下(y:6-8)。
- **河流（水池）**：中间两块 2×3 水域。水格位于 x∈{1,2,4,5}、y∈{3,4,5}。x=0,3,6 为陆地桥。
- **兽穴**：黑方兽穴 (3,0)；红方兽穴 (3,8)。不能进入己方兽穴。
- **陷阱**：每方 3 个，品字形围在己方兽穴旁。黑方陷阱 (2,0)/(4,0)/(3,1)；红方陷阱 (2,8)/(4,8)/(3,7)。敌方动物进入己方陷阱后等级降为 0，己方任意动物可吃。

### 1.2 棋子与等级（每方 8 子，循环克制）

等级从高到低：象(8) > 狮(7) > 虎(6) > 豹(5) > 狼(4) > 狗(3) > 猫(2) > 鼠(1)。

| 动物 | type | rank | emoji | 特殊能力 |
|------|------|------|-------|---------|
| 象 | elephant | 8 | 🐘 | 可吃除鼠外所有动物 |
| 狮 | lion | 7 | 🦁 | 可跳河 |
| 虎 | tiger | 6 | 🐯 | 可跳河 |
| 豹 | leopard | 5 | 🐆 | — |
| 狼 | wolf | 4 | 🐺 | — |
| 狗 | dog | 3 | 🐶 | — |
| 猫 | cat | 2 | 🐱 | — |
| 鼠 | rat | 1 | 🐭 | 唯一可入水；可吃象 |

### 1.3 初始布局

- 黑方（上）：狮(0,0) 狗(1,1) 猫(5,1) 虎(6,0)；鼠(0,2) 豹(2,2) 狼(4,2) 象(6,2)
- 红方（下）：象(0,6) 狼(2,6) 豹(4,6) 鼠(6,6)；猫(1,7) 狗(5,7) 虎(0,8) 狮(6,8)

### 1.4 走法

- 所有动物每步走一格，前后左右四向（不可斜走）。
- **鼠入水**：鼠可进入水格；在水中时陆地动物不能吃它，它也不能从水中吃岸上的象；两鼠在水中可互吃。
- **狮虎跳河**：狮/虎可纵向或横向跳过整片水域，落到对岸第一格陆地，并可吃对岸等级低于自己的动物。若水路中有鼠（无论敌我）阻挡则不能跳。

### 1.5 吃法

- 高等级可吃同级或低等级。
- 例外：鼠可吃象，象不能吃鼠。
- 敌方动物在己方陷阱中等级为 0，己方任何动物可吃。

### 1.6 胜负

1. 任一方动物进入对方兽穴 → 该方胜。
2. 一方所有动物被吃光 → 对方胜。
3. 一方所有存活动物无法移动 → 对方胜。

## 二、JSON 原语重新设计（灵活编码核心）

### 2.1 设计原则

保留 jump/ray + sym + where 框架（通用），**新增动物棋领域原语**：等级吃子、水域、陷阱、兽穴、跳河。所有新规则以 JSON 字段表达，AI 可通过 JSON Patch 修改 rank / exceptions / 水域权限 / 跳河能力等，无需改引擎代码。

### 2.2 棋子定义结构（pieces_red.json / pieces_black.json）

```json
{
  "type": "lion",
  "label": {"red": "🦁", "black": "🦁"},
  "rank": 7,
  "moves": [
    {"kind": "jump", "to": [1,0], "block": [], "land": "any", "sym": "rotate4",
     "where": [{"not": {"in_water": {"pos": "$dest"}}}, {"not": {"in_own_den": {"pos": "$dest"}}}]},
    {"kind": "ray", "dir": [1,0], "max": 3, "screens": 0, "land": "any", "sym": "rotate4",
     "path_constraint": {"must_be": "water", "no_blocker": true},
     "where": [{"not": {"in_water": {"pos": "$dest"}}}]}
  ],
  "capture": {
    "mode": "rank_ge",
    "exceptions": []
  }
}
```

### 2.3 新增字段

**棋子级字段：**
- `rank`：整数，吃子等级（1-8）。
- `capture`：吃子规则对象：
  - `mode`：`"rank_ge"`（默认，攻击方 rank ≥ 防守方 rank 可吃）| `"any_enemy"` | `"rank_le"`。
  - `exceptions`：数组，每项 `{"can_eat": "type"}` 或 `{"cannot_eat": "type"}`（鼠克象、象不吃鼠）。
  - `water_rules`：水域吃子限制：
    - `invulnerable_in_water`：bool，在水中时不可被陆地动物吃（鼠）。
    - `cannot_attack_from_water`：[types]，在水中时不能吃这些岸上动物。

**移动级字段：**
- `path_constraint`（ray 专用）：约束射线经过的中间格：
  - `must_be`：`"water"` | `"land"` | `"any"`，中间格必须满足的地形。
  - `no_blocker`：bool，路径中不能有任何棋子（狮虎跳河被鼠阻挡则失败）。

### 2.4 新增 where 条件原语

| 原语 | 语法 | 含义 |
|------|------|------|
| `in_water` | `{"in_water": {"pos": "$dest"}}` | 目标在水域 |
| `in_trap` | `{"in_trap": {"pos": "$dest"}}` | 目标在陷阱（任一方） |
| `in_enemy_trap` | `{"in_enemy_trap": {"pos": "$dest"}}` | 目标在敌方陷阱（对己方降级用，此处"敌方"指相对棋子所属方） |
| `in_own_den` | `{"in_own_den": {"pos": "$dest"}}` | 目标在己方兽穴（禁止进入） |
| `in_enemy_den` | `{"in_enemy_den": {"pos": "$dest"}}` | 目标在敌方兽穴（获胜） |

**保留**：`in_region`、`at_row`、`at_col`、`not`、`and`、`or`。
**删除**：`crossed_river`、`same_side`、`$palace`、`$forward`（象棋特有）。
