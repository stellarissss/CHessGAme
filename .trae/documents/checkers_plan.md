# 双人跳棋项目开发计划

## 项目概述

基于"无限制象棋"的架构，创建一个支持AI自由修改的双人跳棋游戏。核心特点：
- 标准国际跳棋规则（8x8棋盘，斜向移动，吃子跳跃，升变为王）
- 支持AI"作弊"机制（通过自然语言修改规则）
- 前端设计与象棋保持一致的极简黑白风格
- 棋子使用纯色（红色和黑色圆形）

## 跳棋规则要点

| 规则 | 说明 |
|------|------|
| 棋盘 | 8x8，只在深色格子上放置棋子 |
| 普通棋子 | 只能斜向前移动一格 |
| 吃子 | 跳过对方棋子到空位，可连续吃 |
| 升变 | 到达对方底线变为"王"，可前后移动 |
| 胜利 | 吃掉对方所有棋子或对方无子可动 |

## 开发步骤

### 步骤1：创建目录结构

```bash
mkdir -p checkers/configs/initial checkers/static
```

### 步骤2：配置文件

#### board.json
- 8x8棋盘
- 深色格子区域定义（用于渲染和规则）
- 去掉楚河汉界、九宫格等象棋特有元素

#### pieces_red.json / pieces_black.json
跳棋只有两种棋子：
- `man`（普通棋子）：斜向前移动一格，吃子跳跃
- `king`（王）：斜向任意移动，吃子跳跃

#### rules.json
- 胜利条件：吃掉所有对方棋子、对方无子可动
- 特殊规则：强制吃子、连续吃子、升变规则

#### board_state.json
初始状态：每方12枚棋子，放置在己方3行深色格子上

#### ui_config.json
- 棋子使用纯色（红/黑圆形）
- 保持与象棋一致的配色风格

- 复制象棋main.py

### 强制吃子规则

跳棋的一个重要规则是"强制吃子"——如果有吃子机会必须吃子。这需要在规则引擎中特别处理。

### 连续吃子规则

吃完一个棋子后，如果仍有吃子机会，可以继续吃，直到无法再吃为止。

## 风险与注意事项

1. **规则复杂度**：跳棋的吃子和连续吃子规则比象棋复杂，需要仔细实现
2. **强制吃子**：必须确保规则引擎正确处理强制吃子
3. **升变检测**：需要检测棋子是否到达对方底线
4. **深色格子**：跳棋只在深色格子上移动，需要区域定义和验证
5. **AI评估**：跳棋的评估函数需要重新设计，考虑中心控制、升变等因素
