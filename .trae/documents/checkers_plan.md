# 双人跳棋项目开发计划

## 项目概述

基于"无限制象棋"的架构，创建一个支持AI自由修改的双人跳棋游戏。核心特点：
- 简化跳棋规则（无吃子、无升变）
- 支持AI"作弊"机制（通过自然语言修改规则）
- 前端设计与象棋保持一致的极简黑白风格
- 棋子使用纯色（红色和黑色圆形）

## 跳棋规则要点

| 规则 | 说明 |
|------|------|
| 棋盘 | 8x8，只在深色格子上放置棋子 |
| 普通移动 | 斜向前移动一格到空位 |
| 跳跃移动 | 跳过相邻棋子（己方或对方），跳到后面空位 |
| 连续跳跃 | 完成一次跳跃后，如果仍有跳跃机会，可继续跳跃 |
| 胜利 | 将所有棋子移动到对方底线区域 |

## 关键技术点

### 跳棋JSON原语设计

```json
// 普通棋子（man）
{
  "type": "man",
  "label": "○",
  "moves": [
    {
      "kind": "jump",
      "to": [1, -1],
      "block": [],
      "land": "empty",
      "sym": "mirror_x",
      "where": [{"in_region": {"pos": "$dest", "region": "dark_squares"}}]
    },
    {
      "kind": "jump",
      "to": [2, -2],
      "block": [[1, -1]],
      "land": "empty",
      "sym": "mirror_x",
      "where": [{"in_region": {"pos": "$dest", "region": "dark_squares"}}]
    }
  ]
}
```

### 跳跃规则

跳棋的核心是跳跃机制：
- 跳过相邻的己方或对方棋子
- 跳到后面的空位上
- 可以连续跳跃（完成一次跳跃后，如果仍有跳跃机会，继续跳跃）

### 胜利条件

当一方所有棋子都到达对方底线区域时，该方获胜。

## 风险与注意事项

1. **跳跃复杂度**：连续跳跃规则需要仔细实现
2. **深色格子**：跳棋只在深色格子上移动，需要区域定义和验证
3. **AI评估**：跳棋的评估函数需要重新设计，考虑向底线推进、中心控制等因素
4. **胜利判断**：需要准确检测所有棋子是否到达对方底线
