### Task 6：重写 `dongwuqi/rule_engine.py`（核心）

**目标**：将象棋规则引擎改造为动物棋规则引擎，实现等级吃子、水域、陷阱、兽穴、跳河、胜负判定。

**保留的通用框架**（不动）：
- `RuleEngine.__init__(board, pieces_red, pieces_black, rules)` 签名
- `get_valid_moves(piece, board_state)` 主入口
- `_get_move_definitions` / `_expand_symmetry`（rotate4/rotate4_mirror/mirror_x）
- `_execute_move_def` 分发
- `_jump_moves` / `_jump_region_moves` / `_ray_moves` 主结构
- `_eval_where` / `_eval_condition` 逻辑操作符（not/and/or）+ `_resolve_pos`
- `_in_bounds` / `_get_width` / `_get_height` / `_get_piece_at`

**删除的象棋特有代码**：
- `__init__` 中的 `self._king_types` 及 custom_pieces 的 is_king 收集逻辑（L25-31）
- `_jump_moves` 中 `if to == "$forward":` 分支（L163-165）
- `_eval_condition` 中 `crossed_river`（L311-313）、`same_side`（L315-317）分支
- `_resolve_var` 中 `$palace` 处理（L342-343）
- `_is_in_region` 中 `$palace` 分支（L352-353）
- `_in_palace` 方法整体（L374+）
- `_crossed_river` / `_is_own_side` 方法整体
- `is_in_check` / `is_checkmate` / `is_general_captured` 方法整体（L434-513）

**新增代码**：

1. **区域查询方法**（从 `board.geometry.regions` 的 `cells` 数组查表，缓存为 set）：
```python
def _is_in_water(self, pos) -> bool
def _is_in_trap(self, pos) -> bool           # 任意一方陷阱
def _is_in_enemy_trap(self, pos, side) -> bool
def _is_in_own_den(self, pos, side) -> bool
def _is_in_enemy_den(self, pos, side) -> bool
```
实现要点：`__init__` 中预计算 `self._region_cells = {name: set((x,y)...)}`；trap_red/trap_black/den_red/den_black 分别查表；enemy 相对 side 取反。

2. **`_can_capture(attacker, defender, board_state) -> bool`** —— 等级吃子核心：
   - 读取双方 piece config 的 `rank`（attacker_rank / defender_rank）
   - **陷阱降级**：若 defender 在 attacker 方的陷阱（enemy_trap of attacker），defender_rank = 0
   - **鼠克象**：检查 attacker.capture.exceptions 与 defender.capture.exceptions：
     - attacker 是 rat 且 defender 是 elephant → 可吃（exceptions.can_eat 含 elephant）
     - attacker 是 elephant 且 defender 是 rat → 不可吃（exceptions.cannot_eat 含 rat）
   - **水域规则**（water_rules）：
     - defender 在水中且 `invulnerable_in_water:true` → 攻击者若不在水中则不可吃（水中鼠免疫岸上攻击）
     - attacker 在水中且 `cannot_attack_from_water` 含 defender type → 不可吃
   - **默认规则**：attacker_rank >= defender_rank 即可吃
   - 注意：水中只能有鼠，鼠在水中不能吃岸上象；岸上鼠可吃水中鼠（同级）

3. **`_eval_condition` 新增 5 个操作符**：
   - `in_water`：`_is_in_water(dest)`
   - `in_trap`：`_is_in_trap(dest)`
   - `in_enemy_trap`：`_is_in_enemy_trap(dest, piece["side"])`
   - `in_own_den`：`_is_in_own_den(dest, piece["side"])`
   - `in_enemy_den`：`_is_in_enemy_den(dest, piece["side"])`
   每个 support 简写（字符串）和 dict（含 pos）两种形式，复用 `_resolve_pos`。

4. **`_jump_moves` / `_ray_moves` / `_jump_region_moves` 吃子判定升级**：
   - 原 `target["side"] != piece["side"]` 的位置，改为 `target["side"] != piece["side"] and self._can_capture(piece, target, board_state)`
   - `land == "enemy"` 分支：需 `target` 存在、敌方、且 `_can_capture` 为 True
   - `land == "any"` 分支：友方不可落子；敌方需 `_can_capture` 为 True 才可落子（吃子）

5. **`_ray_moves` 支持 `path_constraint`**（狮虎跳河）：
   - 读取 `move_def.get("path_constraint")`，含 `must_be`（区域名如 "water"）和 `no_blocker`（bool）
   - 跳河是特殊 ray：max_dist 通常为棋盘跨度，但需在每一步检查中间格：
     - 若 `must_be == "water"`：中间所有格必须 `_is_in_water`
     - 若 `no_blocker`：中间格不能有任何棋子
   - 实现方式：在 ray 循环中，对 step>1 的中间格先校验 path_constraint，不满足则 break；终点格按正常 land/capture 逻辑
   - 关键：狮虎跳河是"直线跳过整片水域"，所以 ray 的终点必须是非水格或敌方棋子，中间必须全是水且无棋子（鼠除外——但标准规则鼠在水中会阻挡跳河，所以 no_blocker=true 即可）
   - 跳河方向：仅水平（左右）和垂直（上下），rotate4 展开即可

6. **`check_win(board_state) -> Optional[str]`** —— 胜负判定：
   - **enter_den**：遍历存活棋子，若 red 棋子在 den_black → "red"；若 black 棋子在 den_red → "black"
   - **annihilation**：若一方无存活棋子 → 对方胜
   - **stalemate**：当前方无任何合法移动 → 对方胜（需调用 get_valid_moves 检测）
   - 优先级：enter_den > annihilation > stalemate
   - 返回胜方 "red"/"black" 或 None

7. **`_is_in_region` 简化**：删除 `$palace` 分支，保留 `$full_board` 和通用 regions 查表（支持 `cells` 数组形式）。

**文件头注释**：改为"动物棋规则引擎 v2.0"。

**验证**：`python -m py_compile dongwuqi/rule_engine.py`

## 假设与决策

1. **格子制渲染**：动物棋传统是格子制（每格一子），与象棋交叉点制不同。决策：前端改为格子制，棋子在格子中心。
2. **端口 8003**：避开 8000（xiangqi）/8001（wuziqi）/8002（go）。
3. **emoji 棋子**：🐘🦁🐯🐆🐺🐶🐱🐭，红黑双方用相同 emoji，靠边框色区分阵营。
4. **类名**：`AnimalChessAI`（chess_ai.py）、`DongwuqiBoard`（app.js）、标签 `dongwuqi-board`。
5. **狮虎跳河**：用 ray + `path_constraint:{must_be:"water", no_blocker:true}` + rotate4，引擎在 ray 循环中校验中间格全为水且无棋子。
6. **鼠克象**：通过 `capture.exceptions` 配置驱动，引擎读取 exceptions 判定，不硬编码。
7. **陷阱降级**：defender 在 attacker 方陷阱时 rank 视为 0，任何敌方棋子可吃。
8. **check_win 优先级**：enter_den > annihilation > stalemate。
9. **保留通用框架**：jump/ray/sym/where 体系、机制引擎 5 原语、Minimax+Alpha-Beta、二级 AI 流水线、JSON Patch 全部保留，只改领域语义层。
10. **style.css 处理**：先读取确认角色，若 Shadow DOM 内联样式则 style.css 可能冗余，按需处理。
