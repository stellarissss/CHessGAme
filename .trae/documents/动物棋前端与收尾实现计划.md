#### 第二层：`_getBoardLayoutConfig()` 默认值改为动物棋（L2311-2384）

#### 第三层：`renderBoard()` 从交叉点制改为格子制（L2386-2595）

**viewBox**（L2417-2419）：
- 旧：`viewBoxWidth = (width - 1) + padLeft + padRight`
- 新：`viewBoxWidth = width + padLeft + padRight`（格子制，棋盘宽 = width 个格子）

**网格线**（L2430-2523）：
- 水平线：`y = 0, 1, ..., height`（共 height+1 条），`x1=0, x2=width`
- 垂直线：`x = 0, 1, ..., width`（共 width+1 条），`y1=0, y2=height`
- 删除所有 `riverGap` 分支逻辑（河界断线）
- 删除 `orientation` 分支（动物棋无需旋转棋盘渲染）

**删除 palace 九宫对角线**（L2526-2549）：整块删除。

**边框**（L2550-2567）：`borderRect` 的 width/height 从 `(width-1)`/`(height-1)` 改为 `width`/`height`。

**删除楚河汉界文字**（L2571-2592）：整块删除。

**新增 water/trap/den 装饰渲染**（在网格线绘制后、appendChild(svg) 前）：
从 `this.configs.board?.geometry?.regions` 读取 cells，逐格画 SVG 装饰：
- **水域**：对每个 water cell 画 `<rect x=cx y=cy width=1 height=1 fill="{fill_color}" fill-opacity="{fill_opacity}"/>`，叠加波浪线（`<path>` 用 wave_color 画 ~ 形）。坐标：`cx=x, cy=y`（格子制，左上角对齐网格线）。
- **陷阱**：对每个 trap cell 画半透明 `<rect>` 填充 + 对角十字 `<line>`（两条对角线，stroke=traps.color）。
- **兽穴**：对每个 den cell 画半透明 `<rect>` 填充 + 星标 `<text>`（★，fill=red_color/black_color），居中于格子 `(x+0.5, y+0.5)`。

装饰配置从 `layoutConfig`（合并后的 water/traps/dens）读取。

#### 第四层：棋子定位改为格子制（L2655-2659）
- 旧：`leftPct = 5 + (x / (width - 1)) * 90;` / `topPct = 5 + (y / (height - 1)) * 90;`
- 新：`leftPct = ((x + 0.5) / width) * 100;` / `topPct = ((y + 0.5) / height) * 100;`
- 保留 `transform: translate(-50%, -50%)`（棋子中心对齐格子中心）
- 注意：旧的 `5 + ... * 90` 是因为留了 5% 边距；新公式 `(x+0.5)/width*100` 自动让棋子居中于格子，无需额外边距。

#### 第五层：落子提示圆点定位（L2753-2756）
与第四层同步：`leftPct = ((x + 0.5) / width) * 100` / `topPct = ((y + 0.5) / height) * 100`。

#### 第六层：点击坐标反算改为格子制（L3755-3759）
- 旧：`boardX = (x / rect.width - 0.05) / 0.9 * (width - 1);` + `Math.round`
- 新：`boardX = (x / rect.width) * width;` + `Math.floor`（格子制：点击位置 / 格子大小 = 格子索引，向下取整）
- 同理 `boardY = (y / rect.height) * height;` + `Math.floor`
- 边界校验：`0 <= boardX < width && 0 <= boardY < height`

## 假设与决策

1. **格子制渲染**：动物棋传统是格子制（每格一子），棋子在格子中心 `(x+0.5, y+0.5)`。SVG 坐标系中格子左上角对齐网格线交点。
2. **装饰数据源**：water/trap/den 的 cells 直接从 `configs.board.geometry.regions` 读取，外观从 `configs.board.appearance.{water,traps,dens}` 读取，无需新增配置。
3. **emoji 棋子**：`piece.name` 已是 emoji，无需前端映射；字体族已配，无需改 `_getStyles()`。
4. **style.css 处理**：孤儿文件仅改注释保持术语一致，不删除（避免破坏潜在引用）。
5. **端口 8003**：避开 8000/8001/8002。
6. **viewBox padding**：board.json 已设 `viewbox_padding_*: 0.5`（半格），格子制下 viewBox = `-${0.5} -${0.5} ${width+1} ${height+1}`，四周留半格边距。
7. **保留通用框架**：机制引擎面板、AI 性格面板、Token 统计、指令输入、坐标选择器等 UI 全部保留，只改棋盘渲染与文案。
8. **不使用 frontend-design skill**：本任务是改造既有前端（保持视觉一致性），非从零创建，故不触发 web-dev/frontend-design skill。
