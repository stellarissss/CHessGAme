# 无限制围棋 · Unlimited Go

> 基于「无限制象棋」元引擎架构的围棋变体，支持 AI 自然语言修改规则。

## 📖 项目简介

**无限制围棋**是「无限制棋类元引擎」的第二个参考实现。它在无限制象棋的架构基础上，将所有棋类特定的概念（棋子、规则、棋盘、原语体系）全部替换为围棋版本，验证了元引擎架构的可扩展性——**任何棋类游戏只需替换配置数据和提示词，即可在同一引擎上运行**。

### 核心特性

- **🍃 place/capture/liberty 原语体系**：围棋的落子、提子、气的计算全部抽象为 JSON 原语
- **🤖 双层 AI 协作管线**：意图解析 AI + 代码生成 AI，自然语言即规则
- **🎨 禅意极简风格**：温暖木纹棋盘 + 黑白棋子 + 静谧留白的视觉设计
- **⚡ 完整游戏机制**：气、提子、打劫、禁入点、双虚手终局、数子法计分
- **🧩 可插拔架构**：规则引擎、AI、前端完全解耦，配置驱动一切

## 🚀 快速开始

### 环境要求

- Python 3.9+
- pip

### 安装依赖

```bash
cd WeiQi
pip install -r requirements.txt
```

### 启动服务

```bash
python main.py
```

然后在浏览器打开 `http://localhost:8000` 即可开始对弈。

### 可选：配置 LLM（启用 AI 修改规则）

在环境变量中设置你的 LLM API 密钥，或在 `config_llm.py` 中配置：

```bash
export OPENAI_API_KEY="your-key-here"
```

未配置 LLM 时，AI 修改规则功能会使用 mock 模式，基础对弈功能不受影响。

## 🎮 游戏玩法

### 基础规则

- 黑白双方交替落子，**黑先白后**
- 棋子落在**交叉点**上，落下后不能移动
- 被围住（**无气**）的棋子会被提走
- **不能自杀**（落子后己方无气且不能提对方子）
- **打劫**不能立即回提
- 双方连续**虚手（Pass）**则终局，按**数子法**计算胜负
- **贴目 6.5 目**（白方补偿）

### 操作方式

| 操作 | 方式 |
|------|------|
| 落子 | 点击棋盘交叉点 |
| 虚手 (Pass) | 点击「虚手」按钮 |
| 认输 | 点击「认输」按钮 |
| 悔棋 | 点击「悔棋」按钮 |
| AI 走棋 | 点击「AI 走棋」按钮，或在输入框说「你走一步」 |

### AI 修改规则示例

在底部输入框中用自然语言告诉 AI 你想怎么改：

- 「把棋盘改成 9 路的」
- 「加一个可以斜着连的棋子叫'斜子'」
- 「让黑方可以连走两步」
- 「把贴目改成 7.5 目」
- 「解释一下当前的规则」

### 围棋原语体系（place/capture/liberty）

与象棋的 jump/ray 原语体系不同，围棋使用 place/capture/liberty 三元组：

| 原语 | 含义 | 围棋对应 |
|------|------|---------|
| `place` | 落子规则（在哪里能下） | 空点落子、禁入点 |
| `capture` | 提子规则（什么时候吃子） | 无气则提 |
| `liberty` | 气的计算规则 | 正交相邻为气 |

### 双层 AI 管线

```
用户自然语言
     │
     ▼
┌────────────┐    第一层（意图解析）

      │
      ▼
┌─────────────┐
│ ActionPlanner│   → 拆成具体动作清单
└─────┬───────┘
      │
      ▼
┌───────────────┐  第二层（代码生成）
│ PatchGenerator │  → 生成 JSON Patch
└──────┬────────┘
       │
       ▼
┌──────────────┐   治理层
│ Governance   │   → 安全 & 合规检查
└──────┬───────┘
       │
       ▼
  应用到配置 + 自然语言解释
```

## 🔧 核心模块说明

### rule_engine.py — 围棋规则引擎

核心函数：

| 函数 | 功能 |
|------|------|
| `place_stone()` | 落子 + 提子 + 合法性校验 |
| `get_liberties()` | 计算棋组的气数 |
| `get_group()` | 找出连通棋组 |
| `count_territory()` | 数子法计地盘 |
| `is_valid_move()` | 检查某点是否可落子 |
| `is_game_over()` | 判断游戏是否结束 |

### go_ai.py — 围棋 AI

基于启发式评估的贪婪搜索 AI，评估维度：

- **地盘潜力**：控制了多少交叉点
- **棋子安全**：棋组的气数是否充足
- **进攻性**：能提多少对方的子
- **形状优劣**：星位/天元/急所的位置加成

### ai_orchestrator.py — AI 编排器

协调五层组件完成「自然语言 → 规则修改」的全流程，详见架构设计部分。

## 🎨 设计风格

**禅意极简**，核心要素：

- **温暖木纹**：使用 `#dcb35c` 等木色系列，模拟真实棋盘
- **黑白棋子**：径向渐变 + 阴影，营造立体感
- **静谧留白**：大量使用米白/浅米色背景，减少视觉噪音
- **宋体字**：标题使用 Noto Serif SC / Songti SC，增强东方韵味
- **克制动画**：落子弹跳、提子消散、思考涟漪，点到为止

## 🔄 与无限制象棋的关系

无限制围棋是元引擎架构的**第二个验证实现**。两者共享相同的引擎骨架（FastAPI 服务、AI 编排器、机制引擎、Schema 校验器、前端交互模式），但所有棋类特定的部分完全不同：

| 维度 | 无限制象棋 | 无限制围棋 |
|------|----------|----------|
| 原语体系 | jump / ray | place / capture / liberty |
| 棋子移动 | 走子（从A到B） | 落子（放在空点） |
| 胜负条件 | 擒王 | 数子 / 双虚手 |
| 阵营 | 红 / 黑 | 黑 / 白 |
| 棋盘 | 9×10 有河界 | 19×19 星位 |
| 特殊规则 | 河界/九宫/塞象眼 | 气/劫/禁入点 |
| 视觉风格 | 故宫红金 | 禅意木纹 |
