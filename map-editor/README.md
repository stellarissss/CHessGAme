# 六道大地图编辑器

独立、离线可用的**大地图可视化编辑器**，让你用「点一点、拖一拖、涂一涂」的简单方式，
把六道大陆的 `overworld.json` 从零制作或彻底重制。产出文件可直接替换
`configs/overworld.json` 供游戏加载，无需手工编辑 JSON。

## 快速开始

方式一（推荐，本地预览）—— 用纯静态服务器打开：

```bash
cd CHessGAme/map-editor
python serve.py
# 浏览器打开: http://localhost:5173/map-editor/
```

方式二（与游戏主服务打通，可一键写盘）—— 启动游戏后访问：

```bash
cd CHessGAme
python main.py
# 浏览器打开: http://localhost:8000/map-editor/
```

打开后：

1. 点右上角 **「载入模板」**，从 `template/overworld.json` 起稿；
2. 或点 **「导入 JSON」** 载入现有地图继续改；
3. 编辑完成后点 **「导出 overworld.json」** 下载，或点 **「写入 configs/overworld.json」**
   直接写回游戏配置（方式二时）——刷新游戏大地图即可看到效果。

## 目录结构

```
map-editor/
├── index.html        入口页
├── css/style.css     编辑界面样式
├── js/
│   ├── geom.js       几何工具（布尔网格 ↔ 最少矩形列表 / 洪水填充）
│   └── editor.js     编辑核心（画笔·涂层·贴纸·POI·导入导出）
├── assets/atlas/     游戏贴图副本（编辑器直接复用）
├── template/overworld.json   六道大地图原始配置模板
└── serve.py          本地静态服务器
```

## 玩法：用画笔做地图

编辑器把一整块大陆抽象为 **瓦片网格**，每种图层对应一类地形。选好画笔，在画布上涂：

| 画笔 | 快捷键 | 作用 |
| --- | --- | --- |
| 选择 | `0` | 点选贴纸/交互点，右侧可 `Delete` 删除 |
| 区域画笔 | `1` | 把当前区域「刷」到画布，双击区域列表可改属性 |
| 水域 | `2` | 画海洋/湖泊（不可通行） |
| 山脉 | `3` | 画山脉屏障（不可通行） |
| 道路 | `4` | 画可通行的道路线（路径连接区域） |
| 地形擦 | `5` | 擦除水域/山脉/道路 |
| 油漆桶 | `6` | 洪水填充一整片同色地形（可选填充目标） |
| 贴纸 | `7` | 从图集挑一张瓦片，点击放置装饰物 |
| 出生点 | `8` | 点击设置玩家出生位置 |
| 交互点 | `9` | 放置 NPC / 六道入口（配预设不弹窗） |

**通用操作**

- 左键拖动 = 绘制；**右键拖动 = 平移**；滚轮 = 缩放（以光标为中心）。
- 右侧「画笔大小」可调粗笔刷；`[` `]` 快速增减。
- `Ctrl+Z` 撤销 / `Ctrl+Y` 重做。
- 画布实时显示：纯色大陆轮廓（与游戏一致）、红色实体格、贴纸、POI 徽标、出生点光晕。

## 制作步骤

1. **划分区域**：先建几个区域（如「西北密林」「中央平原」），用区域画笔在画布上涂出
   各自的范围，并在弹窗里给每个区域设主题图集与**轮廓色**。
2. **铺大陆**：用油漆桶或区域画笔把整片大陆“涂满”，保证每个瓦片都有归属区域。
3. **加障碍**：沿海/湖涂水域、沿咽喉涂山脉，形成天然边界。
4. **画道路**：用道路画笔连接各区域入口，玩家才能顺畅到达。
5. **放交互**：设置出生点、NPC（如菩提老者）、六个六道入口。
6. **撒装饰**：用贴纸放建筑、树、标记，让地图更生动。
7. **导出**：校验通过后写回游戏或下载替换。

## 输出格式

编辑器导出的是完整 `overworld.json`，与游戏 `hub/overworld.js` 的解析器完全兼容：

- `regions[]`：任意形状区域以 `rects[]`（矩形列表）表示；单矩形时也会给出 `rect`；
- `roads[]`：以 `rect` 矩形块表示的道路；
- `water_overlays` / `mountain_overlays`：矩形坐标列表；
- 河流（`river_snow` / `river_ridge`）在编辑器里作为普通水域合并处理；
- `regions[].color` 为 0xRRGGBB 整数，游戏渲染时优先采用（否则回退内置配色）。

游戏解析器已扩展支持这些字段（见 `hub/overworld.js` 的区域/道路解析），
并完全向后兼容旧的单 `rect` / 线型道路写法。

## 常见问题

- **贴纸图格不显示？** 图集图片需经 HTTP 服务访问（`file://` 下浏览器禁止 canvas 读图），
  请用 `serve.py` 或游戏主服务打开。
- **「写入 configs」提示下载？** 说明当前是静态服务器，后端写盘接口不可用，
  请改用 `python main.py` 打开，或手动把下载的文件替换到 `configs/overworld.json`。
- **重置画布**：重新「载入模板」即可回到出厂大陆。
